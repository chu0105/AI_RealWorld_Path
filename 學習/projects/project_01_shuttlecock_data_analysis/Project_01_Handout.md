# Project 01：羽球數據自動化分析與品質監控講義

## 1. 專案背景與目標
本專案旨在建立一個自動化的**數據流水線 (Data Pipeline)**，將原始的感測器數據（模擬為 CSV）轉化為具備統計意義的品質報告。這對於「羽球回收自動化」或「工業設備監控」具有直接的應用價值。

## 2. 核心技術棧 (A 級底座技能)
* **Pandas**: 用於結構化數據處理（讀取、清理、填補空值）。
* **NumPy**: 用於高效能數值運算（計算標準差、生成常態分佈數據）。
* **Matplotlib**: 用於數據視覺化，生成直觀的品質趨勢圖。
* **OS**: 處理跨平台的檔案路徑，確保程式在 Windows/Linux 都能一鍵執行。

## 3. 程式碼邏輯詳解

### A. 數據生成 (generate_test_data.py)
* **目標**: 模擬真實工業環境下產生的 1000 筆測試數據。
* **關鍵邏輯**: 使用 
p.random.normal(75, 10, 1000) 生成**常態分佈**數據。
    * 75: 設定品質的中心點。
    * 10: 設定波動範圍（標準差）。這能測試分析系統是否能偵測出異常波動。

### B. 自動化分析 (data_process.py)
1.  **路徑自動化**: 透過 os.path.abspath(__file__) 獲取程式位置，解決「找不到檔案」的報錯。
2.  **數據清理**: 使用 .fillna(0) 處理缺失數據，避免統計報錯。
3.  **統計指標**:
    * **平均值 (Mean)**: 代表品質的整體水準。
    * **標準差 (Std Dev)**: 代表品質的**穩定度**。標準差越大，代表產品品質越參差不齊。
4.  **視覺化報表**: 繪製「穩定區間 (Stability Zone)」，即 $\mu \pm \sigma$（平均值加減一個標準差）。

## 4. 工業應用場景 (為什麼需要這個？)
* **預測性維護**: 當標準差（波動）突然變大時，代表機器人（如 Kinova 手臂）或生產線可能需要保養。
* **品質分級**: 自動將羽球分為「穩定 A 級」或「異常 B 級」。
* **創業演示**: 這是向投資人展示你具備「處理大數據並轉化為決策建議」能力的最佳作品。
